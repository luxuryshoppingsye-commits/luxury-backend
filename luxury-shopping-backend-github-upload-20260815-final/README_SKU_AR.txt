نسخة مصدر الباك إند لمتجر رفاهية التسوق

يتضمن هذا الأرشيف شيفرة الباك إند الحالية ومجلد migrations وإعداد النشر. التعديل الخاص برموز SKU القصيرة موجود في alembic/versions/20261123_01_short_catalog_skus.py، ورقم آخر migration هو 20261123_01.

عند نشر نسخة هذا الأرشيف، إعداد Render المرفق يشغّل python -m alembic upgrade head قبل بدء التطبيق. الترحيل يحول الرموز التلقائية القديمة إلى رموز قصيرة ويحفظ القديمة كمرجع، ويترك الرموز اليدوية كما هي.

هذا الأرشيف لم يُرفع إلى الاستضافة ولم يُطبّق على قاعدة الإنتاج. لا يحتوي ملفات .env أو أسرار دخول أو قواعد بيانات محلية. الإعدادات السرية تبقى داخل إعدادات الاستضافة.
