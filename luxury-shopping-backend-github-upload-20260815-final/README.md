# Luxury Backend

حزمة مصدر الباك إند الحالية، جاهزة للرفع إلى مستودع GitHub الخاص بالباك إند.

## الرفع

فك ضغط الحزمة وارفع محتوياتها إلى جذر مستودع الباك إند بحيث تظهر app وalembic وrequirements.txt وrender.yaml مباشرة. لا ترفع ملف ZIP نفسه بوصفه كود المشروع.

## الإعداد والتشغيل

- نسخة Python المحددة موجودة في .python-version.
- تثبيت الاعتماديات: python -m pip install -r requirements.txt
- إعداد المتغيرات من .env.example محلياً، أو من إعدادات الاستضافة. لا تضع قيماً سرية في GitHub.
- تحديث قاعدة البيانات في بيئتك المصرح بها: python -m alembic upgrade head
- تشغيل الخدمة: python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
- إعداد خدمات Render وأمر عامل الرسائل موجودان في render.yaml، والتفاصيل في RENDER_DEPLOYMENT_SETTINGS.md.

الحزمة لا تحتوي قواعد بيانات أو نسخها الاحتياطية أو ملفات العملاء أو مجلدات التشغيل المؤقتة أو سجل Git. ملف seed_data/uploads_seed.zip يحتوي صور حسابات؛ لم يُضمّن في هذه الحزمة. إعداد Render الحالي يستخدم تخزين Cloudflare R2، ويتجاوز تهيئة الصور المحلية في هذا الوضع. البيانات والصور الحالية تبقى في قاعدة البيانات والتخزين الخاصين ببيئتك.

لم تتغير ملفات المشروع الأصلي أثناء إعداد الحزمة. فحص الحزمة محلي ولا يثبت نشرها على GitHub أو نجاح النشر على الاستضافة.
